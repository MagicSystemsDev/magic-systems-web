# Repository instructions

- Build with Astro and strict TypeScript; preserve static-first output.
- Use native CSS and existing design tokens. Do not add a UI framework without an explicit architecture decision.
- Do not introduce a backend, database, CMS, or unnecessary client-side JavaScript.
- Treat official brand repositories and approved exports as authoritative. Never invent or reinterpret brand assets.
- Accessibility is mandatory: semantic HTML, keyboard support, visible focus, sufficient contrast, and reduced-motion support.
- Do not modify neighboring repositories, including Bank G, Black Rous, or About Me.
- Do not commit or push unless explicitly instructed.
- Run `npm run validate` before completing a task and report any failure.
